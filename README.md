# Site web — TIPE Ilyas Baallal

## Contenu
Le fichier `index.html` est autonome : HTML, CSS et JavaScript sont contenus dans un seul fichier.

Il présente :
- la problématique et la formulation d'optimisation ;
- l'ancrage « Cycles et boucles » ;
- la maquette ESP32 / BH1750 / LED / potentiomètres ;
- le protocole de génération du dataset ;
- le DecisionTreeRegressor et le transfert sur ESP32 ;
- les indicateurs MAE, R², gain énergétique relatif et sûreté ;
- le DOT ;
- les limites et perspectives ;
- les principaux codes et la bibliographie ;
- un explorateur interactif de la cible lumineuse.
